# ほかの先生に配る（ひな形をコピーして使ってもらう）

ほかの先生は、PC の道具（Node・clasp）を使わない。アプリ入りのスプレッドシート（ひな形）を自分の Drive に
コピーして、自分でデプロイする。データも実行の上限も、その先生のものになる。

- 自分と検証用の配置は、今までどおり `deploy-single.js create / deploy`（焼き込み）で配置する。
- コピーした配置は、焼き込みが空のまま動く。初めて開いたときに、**スプレッドシートの持ち主が管理者に、
  そのスプレッドシートが DB になる**（`src/helpers.js` の `ensureCopiedDeploymentBootstrap_`）。

## 配る側がすること

```bash
npm run deploy:single -- template --user <clasp の名前>   # 初回: ひな形を作る
npm run deploy:single -- template                         # 2 回目から: ひな形を新しくする
```

1. 初回だけ、できたスプレッドシートの共有を「リンクを知っている全員・閲覧者」にする。
2. 表示された `…/copy` の URL と、下の「先生がすること」を渡す。

- ひな形そのものは配置しない（push するだけ）。ひな形で授業をしない（児童の回答が入ったものを配らない）。
- ひな形を置くアカウントは、外の人と共有できるアカウントにする（学校のドメインは外との共有を止めていることがある）。
- ひな形には報告先・鍵・先生のメールを入れない（`template` はいつも空で組み立てる）。

## 先生への案内は、コピーしたスプレッドシートの中にある

先生に渡すのは URL と「学校のアカウントで開いて、コピーを作成を押してください」の一言だけでよい。
コピーを開くと、最初のタブ「はじめに」に準備・授業での使い方・困ったときが出る（`src/Guide.js`）。

- 許可の前でも必ず目に入るのはシートだけなので、案内はシートに書く。開いたときにサイドバーやダイアログを
  自動で出すことは、許可の前にはできず、Google の指針でも勧められていない。
- メニュー「回答ボード」→「はじめに（使い方）を開く」は、タブを消したときに出し直すためのもの。
- 準備が済む（先生がウェブアプリを初めて開く）と、「今の状態」が ✅ になり、管理パネルの URL が書かれる。
- 手順の文を変えたら `GUIDE_VERSION` を上げる。下の手順は同じ内容の控え。

## 準備のあとは、管理パネルの「はじめの 4 歩」が案内する

コピーした配置の管理パネルには、いちばん上に「はじめの 4 歩」のカードが出る（`src/AdminPanel.html` の `#first-steps`）。
準備 → 授業をつくる → 児童に URL を配る → 児童のアカウントで開けるか確かめる。済んだ歩はアプリが見て印を付け、
全部済むとカードは出なくなる。焼き込みのある配置（`create` / `deploy`）には出ない。

- 3 歩目は「URLコピー」が成功したとき、4 歩目は先生・共同編集者でない人にボードを返したときに、
  スクリプトのプロパティに印を残す（`src/Guide.js`）。
- URL を配ったのに 4 歩目が済まないときは、カードに「児童が開けないときは」の直し方が出る。
  デプロイの設定の間違いを、アプリの中から知る方法は無い（先生が自分で開く分には、どの設定でも同じに見える）。
- 自動のデプロイ・自動の更新は作れない。Google 既定のプロジェクトのままでは、スクリプトが自分自身を
  Apps Script API で操作できない（2026-11-26 に実物で確かめた。403）。

## 先生がすること（「はじめに」と同じ内容）

1. もらった URL を学校のアカウントで開き、「コピーを作成」を押す。**マイドライブ**に置く（共有ドライブでは動かない）。
2. コピーしたスプレッドシートで、メニューの「拡張機能」→「Apps Script」を開く。
3. 右上の「デプロイ」→「新しいデプロイ」。種類は「ウェブアプリ」。
   - 実行するユーザー: **自分**
   - アクセスできるユーザー: **（自分の学校・市の組織）内の全員**
4. 「デプロイ」を押し、「アクセスを承認」で自分のアカウントを選んで許可する。
5. 表示されたウェブアプリの URL を開く。管理パネルが出れば準備完了。URL はブックマークしておく。
6. 児童には、管理パネルの「ボードを開く」の URL を配る。
7. 授業で使う前に、**児童のアカウントで**その URL が開けるかを 1 度確かめる（下の「開けないとき」）。

### 開けないとき

| 起きること | 理由 | すること |
| --- | --- | --- |
| 先生が開くと「まだ準備できていません」 | 共有ドライブに置いた／持ち主が自分ではない | マイドライブにコピーし直して、もう一度デプロイする |
| 児童が開くと Google のエラーの画面 | 手順 3 の「実行するユーザー」が「アクセスしているユーザー」になっている、または組織の設定で児童が Apps Script を開けない | 手順 3 の設定を確かめる。合っていれば、組織の管理者に相談する（アプリでは直せない） |
| 児童が開くと「同一ドメインのアカウントで」 | 児童と先生のアカウントのドメインが違う | 今は使えない（先生と同じドメインの児童だけが開ける） |

## 新しい版にするとき

コピーした配置は、配る側から更新できない。新しいひな形をコピーし直してデプロイし直す。
**今は、前のコピーのボードの設定・授業・回答は新しいコピーに移らない**（移す道具はまだ無い）。URL も変わる。

## まだ確かめていないこと

- 手でデプロイしたときに、手順 3 の 2 つの欄が最初から正しい値になっているか（`appsscript.json` の値が出るはず）。
- 市の外の組織で、児童のアカウントが「先生として実行」のウェブアプリを開けるか（組織ごとの設定による）。
- 実物のコピーで、初回の準備から管理パネルが出るまで（テストは手元の模擬だけ）。
- 実物のコピーを開いたときに、許可の前に「はじめに」のタブとメニューが出るか（同じく模擬だけ）。
