# 授業専用アプリ（スプレッドシート紐づけ版）: てこのはたらき

1 授業 = 1 スプレッドシート + そこに紐づいたスクリプト。教師として実行するので、
児童アカウントの権限設定に左右されない（本体で 2026-10-29 に起きた
「このウェブアプリへのアクセス権がありません」への対策）。

## 本体（みんなの回答ボード）との違い

| | 本体 | この専用アプリ |
| --- | --- | --- |
| 実行する人 | 開いた人（児童の権限を使う） | 教師（児童の権限は使わない） |
| データ | DB + SA pool + 授業ごとのシート | このスプレッドシートの「回答」シートだけ |
| 授業の切り替え | 管理パネル | 先生の画面（`?view=teacher`） |
| 新しい授業 | 管理パネルで作成 | このフォルダをコピーして `Code.js` の `LESSON` を書き換える |

本体の授業モードの決まりはそのまま守る:
フェーズが「書く / 読む / とじる」を決めてサーバで検証する、「考える」の間は他の児童の回答を返さない、
児童同士に名前を出さない、同じフェーズで送り直したら行を更新する。

## 設置（初回だけ）

教師（学校）アカウントで行う。`organization` は `~/.clasprc.json` の学校アカウントの名前。

```bash
cd lesson-apps/teko
cp appsscript.json /tmp/appsscript.keep.json   # create が上書きするので退避
npx clasp --user organization -P . -I . create --type sheets --title "てこのはたらき_回答" --rootDir .
cp /tmp/appsscript.keep.json appsscript.json
npx clasp --user organization -P . -I . push --force
npx clasp --user organization -P . -I . deploy -d "初版"
```

- `-P . -I .` は必須。付けないと clasp が親フォルダ (本体) の `.clasp.json` を拾って本体に push してしまう
- `create` で教師の Drive にスプレッドシートとスクリプトができる（`.clasp.json` は git に入らない）
- 公開範囲と実行ユーザーは `appsscript.json` の `webapp` で決まる（自分として実行 / ドメイン内の全員）

1. **児童に配る前に、先生が先生の URL を 1 度開いて権限を許可する**（スプレッドシートとメールアドレスだけ）。
   許可していないと、児童が開いたときにエラーになる
2. URL を配る
   - 児童: `…/exec`
   - 先生: `…/exec?view=teacher`（児童が開いても操作は断られる）

## 授業での使い方

- 先生の画面で学級を選ぶ（切り替えると「考える」から始まる。前の学級の回答はシートに残る）
- フェーズのボタンを押すと、児童の画面が数秒以内に切り替わる
- 書いている間（考える / もう一度考える）は、投影部分に人数だけ出る
- 「児童ごとの回答」は名前が出るので投影しない

## 別の先生にも先生の画面を使わせる

スクリプトのプロパティ `TEACHERS` にメールアドレスをカンマ区切りで入れる。

## 既知の限界

- 全員の処理が教師 1 人の実行として数えられる。Apps Script の同時実行の上限（1 人あたり約 30）に
  当たらないよう、児童の画面は 5〜7 秒の揺らぎつき、読み込みは 10 秒の cache を使う。
  40 人を超える同時利用は想定していない。
