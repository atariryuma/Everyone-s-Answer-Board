初回セットアップ

このアプリを使い始めるために必要な設定です。一度だけ行います。

サービスアカウント

Google Cloud Console でダウンロードした JSON キーの内容をそのまま貼り付けます。 スプレッドシートへのアクセスに使います。

データベース

ユーザーと設定を保存するスプレッドシートです。既存の ID を貼るか、自動作成できます。

管理者

アプリ設定を開けるアカウントです。ここで指定したドメインが、利用できる組織の範囲になります。

Google Client ID

任意。OAuth 2.0 クライアント ID を使う場合のみ入力します。空欄のままで問題ありません。

セットアップ完了

設定を保存しました。動作確認をしてから使い始められます。

取得方法

サービスアカウント JSON
  1. Google Cloud Consoleにアクセス
  2. プロジェクトを選択または作成
  3. 「IAMと管理」→「サービスアカウント」
  4. 「サービスアカウントを作成」
  5. アカウント作成後、「キー」タブからJSONキーをダウンロード
スプレッドシート ID
  1. Google Sheetsで新しいスプレッドシートを作成
  2. URLから44文字のIDをコピー（/d/の後の部分）
  3. サービスアカウントをスプレッドシートの編集者として追加
